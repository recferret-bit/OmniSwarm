## Goal

Approaches 2 (direct API keys) and 3 (OpenRouter) become reviewers that do exactly what CLI reviewers do: read the sealed source through the **same MCP bridge**, run the frozen tests, and submit through `submit_audit_report`. OmniSwarm runs the tool-calling loop itself, wrapped as an ACP agent so `runReviewSession` (heartbeats, resume, identity checks, logs) works unchanged. Z.ai GLM works both ways: with a pay-as-you-go key through our loop (`key:zai:glm-5.3`) and with a Coding Plan key through Claude Code (`cli:claude-zai:glm-5.3`). A `scripted` family runs with **no LLM** so CI, the screeners and the demo work without paid keys.

## Demo story (the check in words)

1. `./bin/audit run --repo scripts/demo-fixture --reviewers key:zai:glm-5.3,openrouter:qwen/qwen3.8-max-0902,scripted:baseline --plan` → the plan lists three reviewers with family, vendor (`zai`, `alibaba`, `scripted`), model and the env variable each one will receive (`ZAI_API_KEY`, `OPENROUTER_API_KEY`, none). No key value is printed.
2. `OMNI_HTTP_REPLAY=scripts/provider-fixtures/w03 ./bin/audit run --repo scripts/demo-fixture --reviewers key:zai:glm-5.3,openrouter:qwen/qwen3.8-max-0902 --surface s1` → both reviewers replay recorded provider responses, call `read_file` / `search_code` on the bridge and submit; `submissions/` holds one committed file per reviewer and the report is COMPLETE.
3. `./bin/audit run --repo scripts/demo-fixture --reviewers scripted:baseline,scripted:wrong --surface s1` → finishes in under two minutes with no network; `scripted:wrong` submits a finding whose citation does not exist (input for W06's checker).
4. `./bin/audit check-agents` → new rows: `key:zai` "key present", `openrouter` "key present", `cli:claude-zai` "claude CLI found, ZAI_API_KEY present", `scripted` "ok".
5. `./bin/audit demo` (Docker running) → the bundled fixture is reviewed by the `demo` preset in the normal sandbox; with Docker stopped → the same run uses the read-only host snapshot and every report page is stamped **DEMO — not a review**. `./bin/audit demo --repo /tmp/anything` → refused.
6. With `OMNI_LIVE=1` and the owner's keys: `./bin/audit run --repo scripts/demo-fixture --reviewers key:zai:glm-5.3,openrouter:qwen/qwen3.8-max-0902,cli:claude-zai:glm-5.3 --surface s1` → three live reviews, `meta.json` records each served model and `keyFingerprint`, and `grep -r "$ZAI_API_KEY" reports/<run>` finds nothing.
