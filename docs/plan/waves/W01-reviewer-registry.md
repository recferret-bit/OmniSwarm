## Goal

A **reviewer** (id ≠ family ≠ vendor ≠ model) replaces the four hard-coded adapter names everywhere in the engine. The orchestrator becomes a **phase list** and provider launch becomes a **family registry**, so W03 (families), W04 (passes) and W06 (debate, adjudicate) add files instead of editing shared ones. The existing `cli` reviewers behave exactly as today, `--agents`/`--model`/`--models` keep working as aliases, and the integrity bugs that sit in these files (crash-time `finalized:true`, cross-check on S1, overwritten control evidence, non-atomic writes) are fixed on the way.

## Demo story (the check in words)

1. `./bin/audit run --repo scripts/harness-fixtures/near --agents claude,codex --plan` → the same plan as on `main`, plus a reviewer table `cli-claude-opus (cli/anthropic/opus)`, `cli-codex-gpt-6-1-sol (cli/openai/gpt-6.1-sol)`.
2. `./bin/audit run --repo <fixture> --reviewers cli:claude:opus,cli:codex:gpt-6.1-sol,cli:grok:grok-4.7,cli:agy:gemini-4-argon-high --plan` → a reviewer × surface matrix with 4 × 6 cells (`--assign matrix` default); `--assign round-robin` → today's 6 assignments.
3. `--reviewers openrouter:qwen/qwen3.8-max --plan` → the spec parses (slash allowed) and the plan says "family `openrouter` not installed yet (W03)" and exits 2 — no path contains a `/` from the model.
4. `cp omniswarm.config.example.json omniswarm.config.json && ./bin/audit run --repo <fixture> --preset local-subscriptions --plan` → the owner's default preset is expanded from the config file; a flag overrides the file.
5. `--orchestrator recommended --plan` → prints the recommended orchestrator and the reason (ORCHESTRATION §4.5); no phase uses it yet.
6. `node --test scripts/docker-agent-orchestrator.test.mjs` → the new "crash during cross-check" test kills the run after collection: `meta.json` has `finalized:false`, and `verify-and-adjudicate` reports the run INCOMPLETE with the canonical-submission check executed (R-03).
7. Open `report.html` of the fixture run → each verified-safe control shows its evidence text, with a "model assertion" pill (R-05); the header reads "OmniSwarm" (R-16).
8. `grep -rn "'claude', 'codex', 'grok', 'agy'\|claude|codex|grok|agy" scripts/*.mjs scripts/*.sh bin/audit` → only `reviewer-families.mjs` (the `cli` provider table) and tests.
