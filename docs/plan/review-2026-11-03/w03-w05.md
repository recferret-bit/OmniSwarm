## Gaps to fix (ranked)

1. **[Critical, W04] The real (Docker) review path ignores budgets in sessions.** `docker-agent-orchestrator.mjs:401` calls `review({...})` without `budgets` or `prices`. The effects:
   - no ACP "submit now"/cancel (W04-07);
   - no grok/claude `--max-turns` (W04-08);
   - the API loop maxTurns is 40, not N+3 (W04-09);
   - no `--max-cost-usd` ceiling and no price estimates (W04-11/12).

   Only the bridge counter works. Fix: pass `budgets, prices: request.prices` through `execute` → `review(...)`. Add a unit test that drives `runOrchestratedAudit` with a fake `review` and asserts it receives `budgets.toolBudget`.
2. **[Critical, W03] OpenRouter reviewers cannot run at all.** `agent-session-store.mjs:12` rejects any `identity.model` containing `/`, and every OpenRouter slug does (`qwen/...`, `anthropic/...`). This is reproduced: `session_identity_rejected`. Fix: allow `/` in the regex (for example `^[\w.:/-]{1,128}$`), or validate `identity.model` with the reviewer-spec schema. Add an e2e replay run for `openrouter:qwen/qwen3.8-max-0902` to `e2e/engine/w03.test.mjs`.
3. **[High, W03] The documented replay command is broken.** A relative `OMNI_HTTP_REPLAY` is resolved against the session workspace and ends `live_required`, which is then mislabelled `provider_error`. Fix: `path.resolve` the replay and record dirs in `reviewer-env.mjs` (`reviewerProcessEnv`) or `http-replay.mjs:selectFetch`. Map `live_required` to its own failure reason in `api-acp-agent.mjs:165`. Also re-record `scripts/provider-fixtures/w03/openrouter/` with read_file, then search_code, then submit turns, as demo step 2 promises.
4. **[High, W04/W05] No raw usage records or budget health on the Docker path.** `writePassUsage`/`budgetHealth` are called only from `review-host.mjs`. So real runs have no `harness/usage/**`, W05 shows stub usage (0 calls, $0), and a budget stop without a submission becomes a generic `missing_report` rather than `budget_exhausted_without_submission`. Fix: move the pass loop (archive, brief with `filesRead`, usage write, cost skip, health rows) into one shared module (for example `scripts/review-passes.mjs` → `runPasses(execute, ...)`). Use it from both `docker-agent-orchestrator.mjs:458-465` and `review-host.mjs:57-108`, and feed `budgetHealth` into `report-health.json` / `report-contract.mjs`.
5. **[High, W04] Docker pass loop correctness.**
   - `passesCompleted = passCount` is set even when a pass failed.
   - Pass 2 runs after a failed pass 1.
   - `archivePassSubmission` deletes the canonical submission before pass 2, so a pass-2 failure discards pass-1 work.
   - There is no resume-at-first-unsubmitted-pass.

   Fix in the shared pass loop above. Count only passes with `res.code === 0`, restore the `-pass-(k-1)` submission if pass k produces none, and persist the per-pass state for `--resume-from`.
6. **[High, W03] The Docker demo is not stamped DEMO.** `audit-demo.mjs:109-113` passes no `--preset demo`, and `request.demo` is never set (`docker-agent-orchestrator.mjs:330`). Fix: pass `--preset demo`, or add `demo: true` to the request written by `orchestrate.sh:123` when `OMNI_DEMO=1`. Also stamp `reviewerHtml`/`indexHtml` when `meta.demo`.
7. **[Medium, W03] `servedModel` and `keyFingerprint` never reach reports.** `servedModel` is recorded only in `api-session.json`. Fix: copy it into `workers.json` jobs and `meta.reviewers[]` after each session. The fingerprint is missing on host runs, and claude-zai looks up `ANTHROPIC_AUTH_TOKEN` instead of `ZAI_API_KEY` (`reviewer-env.mjs:29-33` with `provider-cli.mjs:143`). Fix: add an explicit `fingerprintEnv` per family (claude-zai → `ZAI_API_KEY`). Add a test that greps a real `meta.json` for the key value.
8. **[Medium, W04] `budget_exhausted` is never signalled to the session owner** (`bridge-budget.mjs:60`), and the dead `--finalize-only` legacy flag remains (`docker-mcp-bridge.mjs:63,151`). Fix: write `harness/budget-<reviewer>.json` `exhausted: true` and have `agent-session.mjs` read it (or watch the error frame) to cancel. Delete the legacy flag.
9. **[Medium, W04] Budget file race.** A concurrent read-modify-write of `harness/budget-<reviewer>.json` happens across a reviewer's parallel surfaces. Fix: one file per (reviewer, surface), for example `budget-<reviewer>-<surface>.json`, or an atomic lock.
