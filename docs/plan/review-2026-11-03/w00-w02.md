## Gaps to fix (ranked)

1. **High: matrix assignment makes every multi-reviewer `--surface all` report INCOMPLETE and drops findings.** `scripts/report-contract.mjs:191-202` (`expectedAuditors`) and `:215-222` rebuild the expected inventory by round-robin from `meta.agents` and ignore `meta.assign`/`meta.auditors`. Matrix is the default for `--reviewers`/`--preset` (`run-config.mjs:113`). Result: the error "Declared auditor inventory does not match requested scope", only N=6 auditors loaded, the rest reported as "unexpected auditor", and their findings never reach `crosscheck.mjs:loadAuditorFindings` or adjudication. This hits W01 demo 2 and 4 exactly (24 jobs). *Fix:* in `expectedAuditors`, when `meta.assign === 'matrix'`, return every `meta.agents` id × every selected surface (or reuse `assignJobs` from `reviewer-plan.mjs` so one function defines the inventory). Keep the legacy derivation only when `assign` is absent or `round-robin`. Add a `report-contract.test.mjs` case with a 2-reviewer matrix-all fixture, and an orchestrator test or e2e with `--surface all --reviewers a,b`.
2. **Medium: W02 security invariants have no CI and no routine run.** `.github/workflows/ci.yml` excludes `*.docker.mjs`, `check:w02` needs a local image, and w02-check reports that 37 other Docker tests already fail. *Fix:* add a CI job (or a self-hosted runner) that builds `audit-sandbox:local` and runs `node --test scripts/sandbox-hardening.docker.mjs`. Triage or delete the 37 red Docker tests so that `npm run test:docker` can catch regressions.
3. **Medium: bridge reviewer-id check fails open.** `scripts/docker-mcp-bridge.mjs:79-92` checks ids only if `--reviewers-file` is passed, and `scripts/session-smoke.mjs:46` omits it. *Fix:* when `--identity-file` is given, require `--reviewers-file` (or default it to `<reportDir>/harness/reviewers.json`) and throw `IDENTITY_UNKNOWN` if it is absent.
4. **Medium: R-04 is only half fixed. `/out` stays writable by target suites and is a served read root** (`bridge-tools-common.mjs:17`; `sandbox.sh:300-302` `chmod 777 /out`). *Fix:* after the prep stage, copy `/out/harness` leads to a host-side or read-only location (for example a second `:ro` mount of a sealed copy) and serve reviewer reads of leads from there. At minimum, list `/out/harness` content as untrusted in `get_audit_context`.
5. **Medium: R-08 preflight is self-referential** (`agent-hook-preflight.mjs` validates the file `agent-launch.mjs:55-63` just wrote). *Fix:* record a real AGY transcript fixture that proves the hook denies `run_command`, replay it in `check-agents`, and mark AGY `unavailable` in `checkBridgeAgents` until a live proof exists, or drop AGY from presets by default.
6. **Medium: source-digest check accepts a missing file.** `report-contract.mjs:177` treats ENOENT as "no problem". *Fix:* when `meta.sandboxHardening === 1` and any auditor submission exists, require `harness/source-read-digest.json`. Also reconsider the subset acceptance (`:186-188`) and document why it is safe.
7. **Medium: per-run test copies import `node_modules` from writable `/work/src`** (`bridge-tools-common.mjs:265-270`), so one suite can tamper with a later suite's evidence. *Fix:* seal a read-only copy of the prepared `node_modules` at the handoff step (`sandbox.sh:506-523`) and copy from that.
8. **Low/Medium: W00-15 isolation is not wired.** The 9 port buckets collide across real wave branches, and nothing consumes `OMNI_*_PORT` or `OMNI_REPORTS_DIR` (`backend/intake/src/server.ts:3` reads `PORT`). *Fix:* derive `PORT` (or read `OMNI_API_PORT`) in the backend and landing dev scripts, use more buckets (for example a step of 10 over 4100..4990), and make `bin/audit` honour `OMNI_REPORTS_DIR`.

Correct w01-check step 8.

11. **Low: `search_code` silently truncates hits at 220 chars** (`bridge-tools-common.mjs:510`). *Fix:* append `… [+N chars]` the same way the R-12 marker does.
